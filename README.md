# Cinema Ticket Booking System Using Python
"Developed a backend cinema ticket booking system using Python and Object-Oriented Programming (OOP) concepts."
## Project Overview
This project is a console-based Cinema Ticket Booking System developed using Python. It allows users to explore movies, view available shows, book cinema tickets, and manage bookings.

The project demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts in Python.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## OOP Concepts Implemented
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Constructors
- Methods

## Key Features
- Movie management
- Show details
- Ticket booking
- Customer details management
- Booking management

## How to Run the Project
1. Install Python.
2. Clone or download this repository.
3. Open the project folder.
4. Run the main Python file:

```bash
python programmenu.py
```
